PROJECT OVERVIEW & DEFENSE ARCHITECTURE
VERSION 2.4-ENTERPRISE

A2IDS is an autonomous, evidence-driven Network Intrusion Detection & Prevention System designed to safeguard host infrastructure against volumetric attacks, network reconnaissance, and protocol anomalies in real time. It operates directly at the operating system packet filter level, combining heuristic sliding-window detectors with machine learning intelligence and a strict three-tier safety controller.

1. BPF INGESTION (en0)
Direct kernel frame decoding on primary interface en0 with high-throughput 10,000-packet buffer memory.
2. DUAL-ENGINE ANALYSIS
Heuristic SYN-flood, port scan & amplification rules evaluated in parallel with 17-feature Random Forest ML scoring.
3. 3-TIER SAFETY ENGINE
Rigorous lock-out prevention: Category A (loopback/local IPs), Category B (gateways/DNS), Category C (configurable).
4. KERNEL PF MITIGATION
Instantaneous macOS pfctl table drops with kernel state verification (BLOCKED_VERIFIED) for IPv4 & IPv6.
